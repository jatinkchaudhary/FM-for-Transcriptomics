# Publication-ready study diagrams

This directory contains five manuscript-oriented diagrams covering the model
architectures, contextual representation construction, experimental sequence,
and benchmark landscape. Each figure is available as:

- `SVG`: editable vector artwork for figure assembly.
- `PDF`: vector output for manuscript submission.
- `PNG`: 300 dpi raster output for slides and document previews.

All figures are generated by
[`scripts/generate_paper_diagrams.py`](../../scripts/generate_paper_diagrams.py).
The diagrams describe the archived study configuration and should be updated by
rerunning that script if model or protocol metadata changes.

## Figure captions

### Figure 1. BRIDGE architecture

BRIDGE masked-expression reconstruction architecture. A partially observed
gene-expression profile is combined with a learned gene-identity embedding and
processed by a 12-block Transformer encoder. A gene-wise decoder reconstructs
the masked expression values. The archived BRIDGE comparator contains 15,165
genes and is optimized with reconstruction loss only; it does not include an
explicit sequence-prior, contextual-alignment, or sample-contrastive objective.

### Figure 2. Txn_Jatin architecture

Txn_Jatin extends the reconstruction backbone with biologically informed
representation learning. The 16,055-gene model uses ESM2-initialized gene
embeddings, expression rank and value encoding, and a 12-layer, 8-head,
512-dimensional Transformer encoder. Training combines masked-expression
reconstruction with ESM2 gene-prior alignment, expression-conditioned
contextual alignment, and sample-level contrastive learning. The displayed
coefficients are the archived training weights: 1.00, 0.02, 0.03, and 0.01,
respectively.

### Figure 3. Txn_Contextual construction

Construction of the frozen Txn_Contextual gene representation. Txn_Jatin
weights are held fixed while reference expression profiles are passed through
the encoder. For each gene, its expression-conditioned hidden state is averaged
over the reference corpus to obtain a 512-dimensional contextual vector. The
archived 20,000-sample validation construction contains 15,916 genes.
Txn_Contextual is a derived embedding matrix rather than a separately optimized
decoder; it is eligible for representation benchmarks but not expression
imputation.

### Figure 4. Experimental pipeline

End-to-end study design. ARCHS4 pretraining produces static and contextual
Txn_Jatin representations, followed by comparisons with BRIDGE and external
gene models. Evaluation proceeds from representation and reconstruction tests
to OSDR parameter-efficient adaptation, TCGA and GTEx validation, and
sample-level translational pilots. Model capability is respected throughout:
decoder metrics are reported only for models that generate expression values,
whereas embedding models are evaluated on representation-compatible tasks.

### Figure 5. Benchmark landscape and evidence hierarchy

Benchmark families, validation units, and primary outcomes used across the
study. Representation benchmarks include alignment, gene-level annotation, and
gene-pair prediction. Reconstruction benchmarks include random cell masking,
whole-gene masking, and external GTEx recovery. Sample-level tests include
cancer classification, OSDR transfer, and multi-cohort immunotherapy response.
Biological interpretation is assessed through sparse biomarkers, atlas
evidence, and pathway concordance. Language-model output is restricted to
structured evidence summarization and is never used as the predictive signal.
